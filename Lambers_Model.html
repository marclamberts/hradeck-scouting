Methodology — three recruitment philosophies, one blend

▾

Every player is scored 0–100 by three independent sub-models, each built on the per-90 metrics Wyscout exposes, cross-league adjusted by a 6-tier league-strength coefficient (Elite → Youth), and blended into THE LAMBERS MODEL using the weights below. Drag a slider to re-blend the entire 45k-player pool live — the table, charts and stat tiles below recompute instantly.

Bentham

Brentford · FC Midtjylland — statistical "Moneyball" recruitment. Rewards high-volume output, set-piece threat (crosses, aerials, dead-ball delivery) and the 22–27 prime trade-value window. Full league-strength penalty applied.

35%

Jamestown

Brighton · Union SG · Hearts — multi-club data network. Rewards technical/creative ceiling (dribbling, progressive carrying, chance creation) found early in lower-profile leagues, age skewed to 18–22. League-strength penalty heavily damped — hidden gems are the point.

35%

Red Bull

RB Salzburg — pressing/athleticism pipeline. Rewards duels, aerial power, acceleration and transition speed, with the steepest youth curve of the three (peaks 17–20, falls off hard by mid-20s).

30%
Weights normalise to 100% automatically.

Expected Value is a separate OLS regression — log(Market Value) ~ Lambers Index + Age + Age² + log(Minutes) + Position + League Tier — fit only on the players Transfermarkt (via Wyscout) actually lists a value for, then used to predict a value for every player in the pool. It is a model-derived number, not a copy of Transfermarkt's figure, so it can diverge from it in either direction — that gap is the recruitment signal (Value Gap = Expected − Market).
