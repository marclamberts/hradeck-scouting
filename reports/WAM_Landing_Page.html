Waltzing Analytics Model · WAM

Nine models. Three movements. One recruitment decision.

A complete data-driven recruitment-and-analysis system for FC Hradec Králové, built entirely from Wyscout aggregated performance exports across 165 leagues — no Transfermarkt lookups, no event data, no shortcuts. Every player is scored, priced, fit-tested, and shortlisted through the same nine-model pipeline, from raw per-90 stats to a Monte Carlo read on what a signing actually does to the squad.

MOVEMENT I

Foundation

Before a single player can be rated, the system needs to know what "good" looks like for this specific club, trust the data it's fed, and define who's realistically in scope to sign.

01Partial

Playing Identity Model

The anchor everything else measures against: target role profiles per position, plus Hradec Králové's own tactical identity, quantified.

  • 23 statistical role archetypes across 8 positions (ROLE_ARCHETYPES)
  • Club Style Profiles — 5-axis tactical fingerprint, any club comparable
  • Open: target formations and tactical principles aren't yet a standalone editable config
View Role Archetypes →
02Built

Data Pipeline Model

Ingest all 165 Wyscout league files, normalize to per-90 percentiles within the right peer group, and adjust for league strength so a weak-league standout isn't mistaken for a genuine one.

  • Within-league percentile, then league-strength adjusted (AdjustedCompositeScore)
  • Minutes-based rating confidence bands — a 500-minute sample is flagged, not trusted like a 2,500-minute one
View League Power Rankings →
03Built

Player Universe Model

Define who's actually in scope: realistic source leagues Hradec could plausibly buy from, senior vs. youth/reserve team-type, and a live budget ceiling.

  • Every player flagged RealisticSource / WithinBudget / InRecruitmentScope — flagged, never hidden
  • Team-type classification (first team vs. reserve/academy) from squad naming patterns
View Club Power Rankings →
MOVEMENT II

Analysis

Every player in scope gets turned into three honest reads: how good are they (with a confidence range, not a false-precision point number), what should they cost, and would they actually work in Czech football.

04Built

Performance Rating Model

A weighted composite score per role — expressed as a distribution with an uncertainty band, not a single point estimate a scout might over-trust.

  • RatingLow / RatingHigh band, widening for low-minute samples
  • Cross-league comparable via AdjustedCompositeScore
View Position Boards →
05Built

Value & Market Model

Estimate transfer value from performance, age and league strength — never a Transfermarkt copy — with an age-curve peak-value projection and a contract-length discount.

  • Ridge regression: ln(Market Value) ~ Composite + Age + Age² + ln(Minutes) + LeagueStrength + Position
  • EffectiveValueEUR discounts for an expiring contract (floor ~35% inside the last 6 months)
  • Open: wage feasibility — Wyscout carries no wage data at all
View Undervalued & Not Past Peak →
06Partial

Fit & Risk Model

Tactical/physical fit for Czech football specifically, plus a risk overlay for what a human scout still needs to verify in person.

  • Every duel/aerial/tempo metric z-scored against the Czech First League's own norms
  • Deliberately open: injury history and wage data need a source outside Wyscout entirely — flagged, not faked
View Physical / Quick-League Fit →
MOVEMENT III

Decision

The point of the previous six models: a shortlist you can actually act on, a simulated read on what a signing does to the squad, and a way to check — later, against reality — whether any of this was right.

07Built

Shortlist & Scoring Model

One scoring engine, reweighted per recruitment need, instead of four separate hardcoded formulas.

  • Four presets: Like-for-Like, Emergency Depth, Resale Play, Balanced
  • Realistic-source, in-budget, not-past-peak players only
View Shortlist Presets →
08Built

Squad Impact Simulation Model

Monte Carlo squad-level projection — the #1 target's age-curve trajectory folded into the squad's actual composite, versus the status quo.

  • monte_carlo.py's engine (300 simulations) wired into build_club_rankings for the first time
  • P10/P50/P90 marginal-impact range, 3 seasons forward — a range, not a verdict
View Squad Impact Simulation →
09Built

Dashboard & Feedback Model

Visualization kept simple by design, plus the feedback loop: log a real signing, and every rebuild checks the model's prediction against what actually happened.

  • Player-vs-role-profile breakdown, side-by-side comparison, squad-needs heatmap, command palette
  • data/signings_log.csv → predicted vs. actual rating/value, tagged Outperformed / On Track / Underperformed
View Model Calibration →
